How to use it

Questions

Is my CRM file uploaded anywhere?

No. The scan runs in your browser and the file stays on your computer. You can load the page, turn off your internet connection and run it to check.

Which CRMs does it work with?

Any CRM that can export a CSV file, including GoHighLevel, HubSpot, FranConnect and ClientTether. You can tell it which column is which.

What if my export has no call count?

It uses a blank last activity date to find leads nobody worked. It can't count one-touch leads without a call or touch count.

Do I need to include names and phone numbers?

No. It only uses dates, owner, stage, source and call counts, so you can delete personal details before you run it.

Why might the numbers be off?

It only knows what your CRM recorded. Calls logged somewhere else look like no activity, and a bulk import can skew created dates. The scanner warns you when it spots one.
